# Content — 5-Exam Catalog, Taxonomy, Calendar & Blog (`modules/content` · W5a)

> Authoritative source of official exam facts (`AGENTS.md` §4 #1): 5-exam catalog
> (`KPSS · YKS · LGS · ALES · DGS`), subject/topic taxonomy, verified exam calendars, public SEO
> `/bilgi` articles with pgvector RAG embeddings, and official YKS program catalog.

---

## 1. Overview & Architecture

`ContentModule` owns all verified editorial data. It enforces **Guardrail §4 #1**: official dates,
application windows, scoring rules, and placement quotas are **never** free-generated by the LLM or
left to community/coach edits — they always come from `ContentModule` with mandatory trust metadata
(`source`, `sourceUrl`, `verifiedBy`, `verifiedAt`).

- **5 Supported Exam Families (`EXAM_CATALOG` in `@mentor/types`):**
  **`KPSS · YKS · LGS · ALES · DGS`** (with KPSS level variants `LISANS`, `ONLISANS`, `ORTAOGRETIM`).
- **Authoritative Countdown Resolution:** Resolves `users.examType` (and optional KPSS `variant`) → current active exam → nearest upcoming `EXAM_DATE` event. If all official dates are in the past, returns `null` (never a negative or fabricated date).
- **Knowledge Center (`/bilgi`, `info_articles`) & pgvector RAG:**
  - Stores verified Markdown/HTML guides with SEO metadata, licensed 1200×630 WebP covers, and consolidated provenance footers (`article-provenance.ts`).
  - Owns `info_articles.embedding vector(1536)` (content-only, zero PII per §4 #6). Emits `ArticlePublished` (`content.article.published`) on first publish so `AIModule` computes the embedding and writes it back via `ContentService.setArticleEmbedding`.
- **RLS Discipline:** Published articles are publicly readable; drafts and editorial mutations require `SERVICE` / `ADMIN` context (`withServiceContext`).

## 2. API Surface

| Endpoint                                                                        | Purpose                                                                                            |
| ------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------- |
| `GET /v1/content/exams`                                                         | List all active exams across the 5 exam families                                                   |
| `GET /v1/content/exams/by-type/:type`                                           | Current exam for `KPSS\|YKS\|LGS\|ALES\|DGS` (`?variant=` for KPSS)                                |
| `GET /v1/content/exams/by-type/:type/calendar`, `GET .../:slug/calendar`        | Verified exam calendar events (`EXAM_DATE`, `APPLICATION_START`, `APPLICATION_END`, `RESULT_DATE`) |
| `GET /v1/content/exams/:slug/subjects`, `GET .../:slug/topics`                  | Subject & topic taxonomy for mock exams, study sessions, and notebooks                             |
| `GET /v1/content/info-articles?family=&category=&page=`                         | Paginated published `/bilgi` articles                                                              |
| `GET /v1/content/info-articles/featured`, `GET .../:slug`                       | Featured article and single article detail with provenance                                         |
| `POST /v1/content/info-articles/:slug/views`                                    | Anonymous article view counter                                                                     |
| `GET /v1/content/programs/search`, `GET .../universities/:id/campus-experience` | Official YKS program catalog search & editorial campus POIs                                        |
| `POST /v1/admin/content/articles/images/upload-url`                             | `CONTENT_EDITOR` presigned R2 article cover/body image upload                                      |
