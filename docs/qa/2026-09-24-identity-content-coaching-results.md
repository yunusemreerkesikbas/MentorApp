## Execution summary and diagnostics

- Targeted Nest/Vitest suites `auth`, `content`, `admin-content`, `coaching`, `analysis-improvement` and `rls-isolation`: **108/108 passed across six files in 104.38 s** against `mentor_test`.
- Final installed-Chrome real-API run: **13/13 mobile in 1.7 min; 13/13 desktop in 1.6 min**. The viewport projects ran as separate invocations because running both rapidly against one IP reached the intended login/refresh throttle. A combined attempt had 17 passes, five 429-related failures and two tests not started; those failures were not counted as product defects or as passes.
- The I04 case was then extended to sign in through the English protected deep link; its targeted rerun passed **2/2** on mobile and desktop.
- Final installed-Chrome focused mock-API interface run: **24/24 passed in 1.6 min** across both viewports. It covers Blog filters/localization, panel mood/empty day, analysis empty/invalid input, tab loading and notebook handoff. These checks do not prove the corresponding API behavior; the real-API and Vitest results above do.
- Initial interface attempts failed because older fixtures intercepted `localhost:3001` while this isolated build called `localhost:3201`; three fixture files now use the QA API variable. The Blog test also expected an obsolete shortened heading and an ICS link for an event already in the past. After correcting test data, the focused run passed. A later sixth recovery request in one minute correctly received 429; the test now sends only the two real requests needed for the privacy comparison. [Diagnostic screenshot](evidence/2026-09-24-stage2-harness-forgot-429.png) and [Playwright trace](evidence/2026-09-24-stage2-harness-forgot-429-trace.zip) are retained as test-harness evidence.
- The I02 test initially navigated a second tab before its auth refresh finished, which could revoke the refresh family; it now waits for the completed refresh and opens the EN panel directly. The desktop API watcher also restarted during parallel mentorship edits, producing a transient `ECONNREFUSED`; final runs used a stable compiled API against the same test database. Neither diagnostic was counted as a product pass.
- Targeted ESLint for touched web files and web TypeScript check passed. A temporary typecheck failure in concurrent mentorship test fixtures was corrected in that parallel work before the final build. `git diff --check` passed. Full workspace CI was not run; it remains a PR/release gate.
